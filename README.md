# GSWZJ · 改善无止境

> **Kaizen is not a day‘s journey. It is a way of life.**

**GSWZJ** —— 取自 **“改善无止境”** 的拼音首字母，我们是一群致力于将精益生产理念与现场改善实践相结合的同行者。

---

## 🎯 我们关注什么

精益生产的根基在于 **“消除浪费、持续改善、聚焦客户、尊重人性”**。围绕这一核心，我们的探索聚焦于：

| 领域 | 关注点 |
|------|--------|
| 🏭 **现场改善 (Gemba Kaizen)** | 从一线出发，发现并消除生产中的七大浪费 |
| 📊 **精益工具与方法论** | 5S、看板、标准作业、价值流图、Poka-Yoke |
| 🧠 **改善文化** | 问题意识、全员参与、现地现物 (Genchi Genbutsu) |
| 🔄 **持续改善系统** | PDCA循环、DMAIC框架 |

---

## 📁 这里有什么

- **改善工具集** —— 实用的现场改善模板、检查清单
- **案例与复盘** —— 真实的改善案例记录与复盘
- **方法论沉淀** —— 精益生产与六西格玛的结合实践
- **自动化辅助** —— 用代码帮助精益管理变得更轻量、更高效

---

## 🤝 如何参与

改善始于每一个人。“每个人都既是管理的执行者，又是管理的改进者”，我们欢迎以下形式的贡献：

1. **提案与讨论** —— 提出改善想法，分享现场经验
2. **工具共建** —— 贡献可复用的精益工具、脚本或模板
3. **案例分享** —— 用文字记录你身边的改善故事
4. **问题反馈** —— 发现问题本身就是改善的开始

请访问 [Issues](链接) 或 [Discussions](链接) 开始你的第一次“改善提案”。
